# 本地简体中文版

这是用于 Shanling Q2 的个人自用简体中文版，不是山灵官方固件，也不是上游正式中文版本。

## 1.8.6 基线

当前分支为 `update-1.8.6`，直接基于上游正式标签 `1.8.6`（`839f6f8fe4e602a6beb7e54d09700e5f7cb55969`，2026 年 11 月 16 日发布）。保留上游新功能、性能优化和安全修复，没有用旧版本整文件覆盖新实现，也没有修改 Fork 的 `main`。

上游从 1.8.0 起使用原厂 **V1.36**，不再使用 V1.32。本次百度轮询、酷狗歌词跳板及 MIPS 回归均使用 V1.36 的地址。

旧版分别保留在 `update-1.4.8`、`update-1.5.5.fix`、`update-1.6.3` 和 `update-1.7.6`。

## 中文界面

术语继续参考 Apple 的 [iPod classic 2009 简体中文使用手册](https://cdsassets.apple.com/live/6GJYWVAV/user/locale/zh-cn/ma1195_ipod_classic_160gb_user_guide.pdf)：音乐、表演者、有声读物、评价、重复播放、打开/关闭，保留 Cover Flow。Q2 独有功能使用相近风格，不伪称为 iPod 原有功能。

保留原厂简体中文和中文键盘；建议在设备系统设置中选择简体中文。新增页面固定中文，包括主菜单、播放队列、均衡器、主题与显示设置、流媒体设置、书籍、游戏、照片、网络电台、应用商店等。本轮补齐播放列表/专辑视图、扫描歌曲时长、快速导航、位置条、更新通知、电池历史和 Tidal 批量下载等新版选项。

未重写原厂全部中文语言资源，原厂页面仍可能有历史用词。品牌、单位、用户的歌曲/表演者/专辑/文件名及外部服务返回内容不强制翻译。`Podcasts`、`Audiobooks`、`Photos`、`Books`、`Videos` 是存储卡真实目录名，不改名；界面另用中文标签。主题 ID、配置键和协议字段保持上游定义。

自绘文字使用 `patch/localization.h` 的 UTF-8 解码，按码点限制长度并替换非法编码。新版游戏绘制与日期/时间控件也使用此路径；上午/下午的缓冲区为 UTF-8 留足空间。经典主题的滑块提示、扫描页和配对二维码文案会选择含中文字形的字体；阴影与原生文字保持一致。经典主题的设置行支持中文全角冒号分隔标题和值。

`patch/navigation.c` 的改动仅涉及已经位于该文件的文案、设置行分隔和日期绘制，没有向 UI 核心添加新功能；共享解码器单独放在头文件中。

## 百度与国内兜底

- **百度网盘**：保留原厂入口、登录/点击回调与播放 URL 工作线程，不再删除 `list_baidu` 行，也不把百度线程停在永不唤醒的信号量上。流媒体设置可显示/隐藏百度入口；`BAIDU` 追加到原有服务键后面，不改变其他服务的顺序和配置键。Tidal 仍使用上游的按需唤醒。
- **单曲歌词发现**：先请求 LRCLIB；没有同步歌词、忙碌重试用尽、网络或写入失败时，调用原厂酷狗搜索，返回原厂状态以继续允许网易云兜底。酷狗可能匹配到不同版本；网易云的旧接口也可能受账户/服务端策略限制，请预览后保存。
- **封面发现**：保留上游 MusicBrainz Cover Art Archive / iTunes，以及后续原厂酷狗、网易云和百度的搜索流程。
- **批量专辑歌词**：仍只用 LRCLIB，国内歌词回退仅作用于原厂单曲封面/歌词发现，不改变批量下载语义。

原厂百度登录、实际播放和第三方歌词/封面的在线可用性仍需实机验证；主机测试不等同于真实账号和网络验收。上游有关文件名、歌词保存、封面复制和目录删除的安全修复保留，不恢复旧版 shell 拼接实现。

## 构建材料

保留上游原始 V1.36 ZIP 的完整 SHA-256 校验：

```text
4e298cab6c12d86cfc55565645f7e3ae11d3fb44677a93ca13991e7184ecec4e
```

山灵英文下载页目前仍提供 V1.32。也可使用原厂 OTA 提供的 `update_V1.36.tar`，本分支单独固定其**完整归档** SHA-256：

```text
7f57884420e324ac3263571d96a35f04bbef79f35dac34162655c5822bdaa684
```

OTA 的主程序与上游 `DEMO_SHA` 一致：

```text
e65d638d6e70332b4c3193af8ac2044941ec0157d20e41e40233aac5b0c2c59f
```

仅这两种精确字节输入被接受；不是按扩展名或版本号放行，也没有绕过原有二进制、资源、包结构和大小校验。`manifest.json` 的兼容字段 `input_zip_sha256` 记录实际输入归档哈希，输入 TAR 时即为上述 OTA 哈希。

本机工具位于忽略版本管理的 `work/toolchain/`：

```bash
export PATH="$PWD/work/toolchain/bin:$PATH"
.venv/bin/python tools/build.py /tmp/Q2-update-V1.36.tar \
  --out /tmp/q2-cn-186-dev --dev
```

开发构建分配独立 `Vxxx i` 标记（无空格），可覆盖先前开发包。请以实际 `manifest.json` 的 `version`、`dev` 和 `source_sha256` 为准。已有完整输出时应换新目录。与上游一样，`--dev` 会启动带密钥的 `q2remote` 调试服务；本包用于开发验收。
